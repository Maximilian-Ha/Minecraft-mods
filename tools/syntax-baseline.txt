# Baseline fuer tools/syntax-check.sh
#
# Hier stehen javac-Meldungen, die NICHT auf einen Fehler in unserem Code hindeuten,
# sondern reine Folgefehler der fehlenden Minecraft-/NeoForge-API sind. Sie treten nur
# auf, wenn ohne Zugriff auf maven.neoforged.net / libraries.minecraft.net kompiliert
# wird. Das Skript meldet nur Abweichungen von dieser Liste.
#
# JEDE Zeile wurde einzeln geprueft. Nichts ungeprueft ergaenzen.
#
# Die Eintraege stehen bewusst OHNE Zeilennummer: sonst gaelte jede Meldung nach einer
# Einfuegung weiter oben in derselben Datei faelschlich als neuer Fehler.
#
# ---------------------------------------------------------------------------------
# Kategorie 1: "types X and Y are incompatible; ... inherits unrelated defaults ..."
# ---------------------------------------------------------------------------------
# Nachweis am Beispiel ProxyComboBlockEntity:
#   IEnergyReceiverMK2.trySubscribe(Level, DirPos)              -> 2 Parameter
#   IFluidReceiverMK2.trySubscribe(FluidType, Level, DirPos)    -> 3 Parameter
# Unterschiedliche Stelligkeit: in gueltigem Java kollidieren diese Default-Methoden
# nicht. javac haelt sie nur deshalb fuer gleich, weil Level/FluidType/DirPos waehrend
# der Fehlerbehandlung Error-Typen sind und die Signaturen dadurch zusammenfallen.
# Die Faelle "types X and X are incompatible" (identischer Name auf beiden Seiten) sind
# derselbe Effekt: javac fuehrt dasselbe Interface durch Fehlerbehandlung doppelt.
# Gegenprobe: `javac -sourcepath src/main/java src/main/java/api/hbm/fluidmk2/*.java`
# uebersetzt dieselbe Hierarchie fehlerfrei.
# Zusaetzlicher Nachweis: MachinePollutingBlockEntity implementiert
# IFluidStandardSenderMK2 nur EINMAL, javac meldet den Konflikt aber trotzdem
# "from types IFluidStandardSenderMK2 and IFluidStandardSenderMK2" -- dieselbe
# Schnittstelle auf beiden Seiten. Ein echter Default-Methoden-Konflikt ist das
# per Definition nicht. Wortgleich meldet javac das auch fuer die bereits
# ausgelieferte TurbineBaseBlockEntity, die in der CI fehlerfrei uebersetzt.
#
